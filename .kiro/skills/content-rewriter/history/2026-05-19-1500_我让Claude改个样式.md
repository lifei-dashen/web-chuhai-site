# 我让 Claude 改个样式，它居然反过来教我做事

那天我让 Claude Opus 4.7 改一段代码。就一个特别小的事——组件的样式从 flex 改成 grid。

我寻思 30 秒就完事了。

结果好家伙，它给我回了一大段话，认认真真地跟我解释为什么 flex 在我这个场景下"更合适"。

兄弟，我让你改你就改，我又没问你哪个好= =

我看着那段话愣了几秒，心说这玩意是飘了？啥时候开始，让一个 AI 干个活，它还能反过来教我做事了？

——

我用 Claude 和 Codex 的比例，年初是 8 比 2，Claude 主力。

今天大概 5 比 5。

这两个月没发生啥别的事，就一件——Claude 自己开始端着了。

Opus 4.7 上线那阵子，社区里反馈就一直不太对劲。

我自己也是,改样式那事不是孤例。它写代码会犯一些低级错误,有时候你还得跟它辩半天,它才肯老老实实干活。

我之前做 AIHOT 手机端适配那次最离谱。Claude 给我做出来的就是一坨屎,关键是——属于改都很难改的那种。我直接整个甩给了 Codex,一轮搞定。

那之前 Claude 主力的时候,做这种活我基本是不带怀疑的。

对了,你再看这俩公司这两个月的动静。

Codex 那边一个接一个：Computer Use、内置浏览器、Codex for Chrome、生图、Hooks,今天又上了远程控制。

Claude Code 这边……emmm,基本没什么声音。

AI 这赛道,3 个月不更新就是退步。Codex 是追着用户跑,Claude Code 现在的感觉是站在那等用户来用。

还有一个特别现实的事。

我们公司小伙伴,主力其实都不用 Claude 了。理由也朴素,三个字——

不封号。

之前经常听到鬼哭狼嚎,"我账号又被封了"、"今天干不了活了"。自从全员切到 ChatGPT 那边,这种声音就再也没有了。

封号是反滥用还是误伤,外人说不清。但对我们这种每天靠它吃饭的人,体感就两个字：担惊。

——

当然 Claude 我现在还在用,写代码以外的活,比如内容创作,我依然觉得 Opus 系列是天花板。所以这篇不是劝退贴。

但说实话,Claude 现在就像一个开始端着的工程师。我找你来不是让你思考人生的,是来干活的。

Anthropic 你最好快点醒过来。说不定下个月你又打了什么鸡血开始猛猛更新,我也不意外。但用户的使用习惯一旦切走了,真的就不会回来了。

剩下的,让两家接着卷吧。咱用户白嫖红利就完事了。
